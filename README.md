# HONEX Avito Parser

Парсер объявлений Avito для тестового задания HONEX.

Парсер берёт список артикулов, формирует поисковые ссылки Avito, получает HTML-страницы, достаёт объявления, фильтрует их по условиям задания и сохраняет результат в CSV.

## Что ищем

Артикулы из задания:

- `223112R020`
- `233002F700`

Условия поиска:

- регион: Москва и Московская область
- состояние товара: новое
- сортировка итогового результата: от меньшей цены к большей
- максимум 5 самых дешёвых объявлений на один артикул

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить из корня проекта:

```bash
python -m honex_parser
```

Если проект не установлен как пакет, можно указать `PYTHONPATH`.

PowerShell:

```powershell
$env:PYTHONPATH="src"; python -m honex_parser
```

После запуска результат сохраняется в файл:

```text
result/result.csv
```

## Docker

Сборка образа:

```bash
docker build -t honex-parser .
```

Запуск:

```bash
docker run --rm -v ./result:/app/result honex-parser
```

## Зависимости

Основные зависимости:

- `httpx` — HTTP-запросы к Avito
- `beautifulsoup4` — разбор HTML

Проект рассчитан на Python 3.10+.

## Как задаются параметры поиска

Базовые настройки находятся в `src/honex_parser/config.py`.

Регион задаётся через:

```python
region_slug = "moskva_i_mo"
```

Состояние товара задаётся через:

```python
condition_value = "new"
```

Сортировка задаётся через:

```python
sort_value = "price_asc"
```

В коде дополнительно выполняется своя сортировка найденных объявлений по числовой цене, чтобы итоговый CSV соответствовал заданию.

## Работа с Avito

Парсер не обходит CAPTCHA, авторизацию, блокировки и другие средства защиты Avito.

Если прямой запрос к Avito недоступен, программа пробует взять сохранённую HTML-страницу из папки:

```text
tests/fixtures
```

Файлы называются по шаблону:

```text
html_<артикул>.html
```

Например:

```text
tests/fixtures/html_223112R020.html
```

Это сделано специально для случая, описанного в задании: если Avito блокирует прямой запрос, можно показать обработку сохранённых HTML-страниц.

## Что попадает в результат

В `result/result.csv` сохраняются поля:

- искомый артикул
- поисковый запрос
- заголовок объявления
- цена числом
- город или регион
- состояние товара
- ссылка на объявление
- место по цене среди отобранных объявлений
- дата и время проверки
- статус
- ошибка, если она была

Если подходящих объявлений нет, добавляется строка со статусом `не найдено`.

Если страницу не удалось получить и нет сохранённой HTML-страницы, добавляется строка со статусом `ошибка`.

## Что учитывается при фильтрации

После парсинга объявления:

- объявления без числовой цены не участвуют в выборе топ-5
- дубли в рамках одного артикула убираются по ссылке
- остаются только объявления с состоянием `новое`
- остаются только объявления из Москвы и Московской области
- результат сортируется по возрастанию цены

## Затраченное время и сложности

На выполнение ушло около 2 часов.

Основная сложность — прямые запросы к Avito могут возвращать CAPTCHA или страницу блокировки. Обход таких ограничений не реализовывался, так как это не требуется по заданию. Для проверки парсинга используются сохранённые HTML-страницы.

ИИ использовался как помощник при проектировании структуры, написании отдельных функций, проверке edge cases и формулировке README. Итоговая логика проверялась вручную на сохранённых HTML-файлах.
